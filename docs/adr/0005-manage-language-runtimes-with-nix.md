# Manage language runtimes with Nix

Declare regularly used runtimes such as Node.js, Bun, Python, and uv in the shared Home Manager configuration and treat Nix as their source of truth. mise, nvm, nodebrew, and pyenv make it easy to select current or environment-specific versions, but can cause PATHs and active versions to diverge between macOS and WSL. Retain them as former or fallback configurations, without maintaining them to the same standard as Nix. Neovim's LSP servers, formatters, linters, DAP adapters, and other executables follow the same Nix source of truth. Fish no longer activates mise during startup, so the Nix-managed runtime remains authoritative while the mise configuration stays available as an explicit fallback.
